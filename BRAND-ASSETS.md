# Travel-Drip Logo Assets

This folder contains the Travel-Drip logo redesign system.

## Core SVG Files

- `icon.svg` - primary PWA/app icon with rounded background.
- `traveldrip-logo-icon.svg` - transparent icon-only mark.
- `traveldrip-logo-full.svg` - primary full-color logo with wordmark and tagline.
- `traveldrip-logo-secondary.svg` - secondary compact logo without tagline.
- `traveldrip-logo-horizontal.svg` - compact horizontal logo.
- `traveldrip-logo-stacked.svg` - stacked logo for square placements.
- `traveldrip-logo-light.svg` - logo on a light background.
- `traveldrip-logo-dark.svg` - logo on a dark navy background.
- `traveldrip-logo-black.svg` - monochrome black version.
- `traveldrip-logo-white.svg` - monochrome white version.

## Logo Concept

The mark combines a minimalist globe, a dynamic airplane, a curved travel path, and a droplet location pin to represent global trips, movement, shared experiences, and the "Drip" in Travel-Drip.
